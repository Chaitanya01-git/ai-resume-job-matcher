# 📄 AI Resume & Job Matcher

An AI-powered web application that analyzes resumes, compares them with job descriptions, calculates ATS compatibility scores, and recommends relevant job opportunities.

## 🚀 Features

✅ Upload Resume in PDF format
✅ AI Resume Analysis using Groq API
✅ Resume Score /100
✅ Job Match Percentage
✅ Strengths & Weaknesses Detection
✅ Missing Skills Identification
✅ Improvement Suggestions
✅ Smart Job Recommendations
✅ Direct LinkedIn Job Search
✅ Direct Naukri Job Search

## 🛠 Tech Stack

* Python
* Streamlit
* Groq API
* pdfplumber
* Regex / NLP Logic

## 🔐 API Key Setup

This project uses Groq API for AI-powered resume analysis.

Create your API key and add it in Streamlit secrets or local environment:

```
GROQ_API_KEY="your_api_key_here"
```

## 💡 How It Works

1. Upload your resume PDF
2. Paste a job description
3. Click **Analyze Resume**
4. Get Resume Score & Job Match %
5. View AI insights and suggested jobs
6. Open LinkedIn / Naukri job links instantly
